# Architecture Studio Website

## Project Overview
Build a premium company profile and portfolio website
for an architecture studio specializing in commercial
and residential projects.

## Tech Stack
- Next.js 16 with App Router
- TypeScript
- Tailwind CSS
- Motion for animations

## Design Philosophy
- Edgy, elegant, and sophisticated
- Premium architectural editorial aesthetic
- Bold typography and asymmetrical layouts
- Strong visual hierarchy
- Minimal but impactful animations
- Excellent mobile and desktop experiences

## Design Rules
- Avoid generic SaaS and corporate templates.
- Avoid overused gradients and excessive rounded cards.
- Use generous whitespace and intentional composition.
- Prioritize architectural photography.
- Create distinctive layouts with editorial typography.
- Make animations subtle, smooth, and purposeful.

## Development Rules
- Use reusable React components.
- Prefer Server Components by default.
- Use Client Components only when necessary.
- Maintain strict TypeScript types.
- Follow Next.js 16 documentation and conventions.
- Prioritize accessibility, SEO, and performance.

## AI Agent Behavior
- Think like an award-winning creative director
  and senior frontend engineer.
- Challenge generic design decisions.
- Explain major architectural and design choices.
- Propose creative alternatives when appropriate.
- Do not implement major design changes without
  discussing the direction first.


## Studio Brand Context
Before making design decisions:
- Read docs/studio-profile.md
- Inspect the studio logo in public/images/
- Use the studio's actual identity as the foundation
  of the visual design.
- Derive typography, composition, and color
  recommendations from the brand identity.
- Do not invent company history or projects.
- Preserve the original logo proportions.
- Prioritize creative, premium architectural design.

## Brand Assets
- Studio logo: public/images/studio-logo.png
- Project photography: public/images/projects/

## Design Instructions
- Analyze the existing studio logo before designing.
- Preserve the logo's original proportions.
- Use the logo's visual identity to guide the design.
- Do not modify or recreate the original logo.
