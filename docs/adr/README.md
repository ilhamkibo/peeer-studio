# Architecture Decision Records

ADR mencatat keputusan teknis penting beserta konteks dan konsekuensinya.
Keputusan yang telah diterima tidak diedit untuk mengubah sejarah; perubahan
arah dibuat sebagai ADR baru yang menggantikan ADR sebelumnya.

## Daftar ADR

- [ADR-0001: Technology stack](./0001-technology-stack.md)

## Status ADR

- `Proposed`: masih dalam pembahasan.
- `Accepted`: disetujui dan menjadi acuan implementasi.
- `Superseded`: digantikan oleh ADR yang lebih baru.
- `Deprecated`: tidak lagi direkomendasikan.
